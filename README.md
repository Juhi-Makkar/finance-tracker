# Personal Finance Tracker

A full-stack personal finance management web application.

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Chart.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Auth: JWT

## Setup Instructions
1. Run `npm install`
2. Configure `backend/.env` with your MongoDB URI and JWT secret
3. Run `npm run dev` to start the development server
4. Open `frontend/pages/index.html` in your browser

## Features
- User Authentication
- Income & Expense Tracking
- Analytics & Charts
- Calendar View
- Budget Planner
- Savings Goals
- Premium Theme Studio
- Export to PDF & Excel
